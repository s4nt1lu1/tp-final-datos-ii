# Notebooks de la versión 1 (registro)

Estas notebooks documentan el trabajo de la versión 1 (modelo `v1.0.0`) con las salidas
de su última ejecución. Usan módulos de `src/` que ya no están en esta rama, así que no
se ejecutan desde acá. Para correrlas:

```bash
git switch --detach v1.0.0
```

| Notebook | Contenido |
| --- | --- |
| `eda.ipynb` | Exploración de los Excel de la versión 1. |
| `correccion_fechas.ipynb` | Desarrollo de la limpieza horaria, hoy en `src/limpieza_horaria.py`. |
| `exploracion_produccion.ipynb` | Exploración de las hojas de producción. |
| `preprocesamiento.ipynb` | Preprocesamiento y selección de la versión 1 (entrega de la Fase 2). |
| `preprocesamiento_gena.ipynb`, `preprocesamiento_lio.ipynb` | Trabajo previo de preprocesamiento de cada integrante. |
| `modelado.ipynb` | Modelado de la versión 1 (entrega de la Fase 3). |

La versión entregada es la 2. Sus notebooks están en `notebooks/`.
